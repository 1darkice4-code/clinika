# Clinika Aesthetics MVP

Веб-сервис для клиники эстетической медицины: публичный лендинг, онлайн-запись, простая CRM, расписание, роли, уведомления, аналитика, аудит и документация эксплуатации.

## Стек

- Next.js App Router
- TypeScript strict
- Tailwind CSS
- PostgreSQL
- Prisma
- Vitest
- Playwright
- Docker Compose

## Быстрый запуск

В текущей среде Node.js не установлен, поэтому команды нужно выполнять в окружении с Node.js 22+.

```bash
npm install
cp .env.example .env
docker compose -f docker-compose.dev.yml up -d
npx prisma migrate deploy
npm run db:seed
npm run dev
```

Сайт: http://localhost:3000

CRM: http://localhost:3000/admin

Development users:

- `owner@clinika.test / DevPassword123!`
- `admin@clinika.test / DevPassword123!`
- `specialist@clinika.test / DevPassword123!`

Эти учетные данные предназначены только для development.

## Архитектура

Архитектура описана в [docs/stage-01-architecture.md](docs/stage-01-architecture.md).

Ключевой принцип: лендинг является CMS-first. React-компоненты рендерят опубликованные данные из БД, а контент, услуги, специалисты, отзывы, документы и SEO редактируются через административную часть.

## Роли

- `OWNER`: полный доступ.
- `ADMIN`: CRM, заявки, записи, расписание, контент, настройки, уведомления, аналитика.
- `SPECIALIST`: свое расписание и свои записи.

Права проверяются на сервере через RBAC.

## Миграции и seed

Стартовая миграция находится в `prisma/migrations/000001_init/migration.sql`.

Seed создает:

- настройки клиники;
- роли и права;
- тестовых пользователей;
- категории и услуги;
- 3 специалистов;
- графики работы;
- юридические документы;
- секции главной страницы;
- отзывы, галерею, клиентов, заявку и запись.

## Тесты

Unit:

- нормализация телефона;
- расчет слотов;
- переходы статусов;
- UTM-атрибуция;
- шаблоны уведомлений;
- идемпотентность.

Integration:

- smoke-проверка БД и seed при наличии `DATABASE_URL`.

E2E:

- открытие публичного лендинга и формы записи.

## Безопасность

Реализовано в MVP-основе:

- HTTP-only session cookie;
- серверные сессии;
- bcrypt-хеши паролей;
- RBAC;
- rate limiting публичных форм и входа;
- honeypot;
- idempotency key;
- аудит значимых действий;
- маскирование чувствительных данных в логах;
- security headers;
- фиксация версий согласий.

## Юридическое предупреждение

Юридические документы в seed являются техническими шаблонами. Финальные тексты, процессы обработки персональных данных, cookie-уведомление, публикация фото до/после и медицинские дисклеймеры должны быть проверены профильным юристом в юрисдикции клиники.

## MVP-ограничения

- Реальные email/SMS/Telegram/WhatsApp провайдеры не подключены.
- Уведомления работают через локальную запись в БД.
- Импорт клиентов не реализован.
- Онлайн-оплата не реализована.
- Медицинские карты, диагнозы, назначения и анализы намеренно не реализованы.
- UI редактирования контента пока минимальный; серверные API уже заложены.
