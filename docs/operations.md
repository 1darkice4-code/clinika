# Операционная инструкция

## Добавление услуги

1. Войти в CRM под `OWNER` или `ADMIN`.
2. Открыть раздел `Контент`.
3. Создать или изменить услугу через API/admin UI.
4. Указать:
   - название;
   - slug;
   - категорию;
   - краткое и полное описание;
   - цену;
   - длительность;
   - буферы;
   - предупреждения и противопоказания.
5. Проверить публичную страницу услуги.

## Добавление специалиста

1. Создать пользователя, если специалист должен входить в CRM.
2. Создать профиль специалиста.
3. Привязать услуги через `SpecialistService`.
4. Настроить рабочее расписание.
5. Проверить слоты на публичной форме.

## Настройка расписания

Расписание состоит из:

- недельного графика `WorkSchedule`;
- исключений `ScheduleException`;
- ручных блокировок `TimeBlock`;
- длительности и буферов услуги.

Свободные слоты считаются только сервером.

## Уведомления

В MVP используется локальный режим:

- уведомление создается в таблице `Notification`;
- сбой уведомления не отменяет заявку или запись.

Для подключения провайдера нужно реализовать адаптер в `src/domain/notification` и добавить секреты в `.env`.

## Экспорт

Экспорт клиентов доступен только пользователям с permission `clients.export`.

Факт экспорта пишется в `AuditLog`.
