# Backup и восстановление

## PostgreSQL

Пример backup:

```bash
pg_dump "$DATABASE_URL" --format=custom --file=backup_$(date +%F_%H-%M).dump
```

Пример восстановления:

```bash
pg_restore --clean --if-exists --dbname "$DATABASE_URL" backup_2026-07-04_10-00.dump
```

## Медиафайлы

Если используется локальное хранилище, каталог uploads должен архивироваться отдельно.

Если используется S3-совместимое хранилище, нужно настроить:

- versioning;
- lifecycle policy;
- ограниченный IAM-доступ;
- регулярную проверку восстановления.

## Рекомендации

- Частота: ежедневно для MVP, чаще при активной записи.
- Retention: минимум 14 ежедневных и 3 месячных копии.
- Шифрование: обязательно для копий с персональными данными.
- Тест восстановления: минимум раз в месяц.
- Ответственный: владелец инфраструктуры клиники.

## Проверка восстановления

1. Поднять временную БД.
2. Восстановить dump.
3. Запустить миграции.
4. Проверить вход в CRM, список клиентов и записи.
5. Удалить временное окружение.
